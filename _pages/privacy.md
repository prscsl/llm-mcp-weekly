본 방침은 **LLM·MCP 위클리**(이하 "본 사이트")가 사용자의 개인정보를 어떻게 수집·이용·보관·공개하는지 안내합니다.
본 사이트는 [GitHub Pages](https://pages.github.com/)에서 정적으로 호스팅되는 비상업·익명 운영 블로그이며, 회원가입·로그인·결제 기능을 제공하지 않습니다.

**최종 갱신일**: 2026-05-06

---

## 1. 본 사이트가 직접 수집하는 정보

본 사이트는 사용자로부터 **직접 수집하는 개인정보가 없습니다**. 회원가입·뉴스레터 구독·댓글 기능을 운영하지 않으며, 폼·로그인 기능도 제공하지 않습니다.

## 2. 자동 수집되는 정보 (호스팅 인프라)

본 사이트는 GitHub Pages를 통해 제공되며, GitHub의 인프라가 다음 정보를 일반적인 웹 서버 로그 형태로 처리할 수 있습니다.

- 접속 IP 주소
- 브라우저 종류 및 버전
- 접속 일시
- 요청 URL · Referrer
- HTTP 응답 코드

이 정보는 GitHub의 보안·운영 목적으로 사용되며, 본 사이트 운영자에게는 제공되지 않습니다. 자세한 내용은 [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)를 참고하세요.

## 3. 쿠키

현재 본 사이트는 자체적으로 쿠키를 사용하지 않습니다.
향후 분석·광고 도구를 도입할 경우 본 항목을 갱신하고, 쿠키 동의 안내를 별도로 제공합니다.

## 4. 제3자 서비스 (도입 예정)

본 사이트는 운영 효율과 지속 가능성을 위해 다음 외부 도구의 도입을 검토 중입니다. **도입 시점에 본 방침을 사전 갱신**하며, 도입 전까지는 활성화되지 않습니다.

| 서비스 | 용도 | 상태 |
|--------|------|------|
| Google Analytics 4 | 익명 트래픽 분석 | **미도입** |
| Google AdSense | 광고 수익화 | **미도입** |
| Naver Search Advisor / Google Search Console | 검색 인덱싱 | 등록 검토 중 (개인정보 수집 아님) |

도입 시 각 서비스가 자체적으로 수집·처리하는 정보는 해당 서비스의 개인정보 처리 방침을 따릅니다.

## 5. 외부 링크

본 사이트는 RSS·GitHub Releases·HackerNews 등 외부 원문 링크를 다량 제공합니다. 외부 사이트에서 처리되는 사용자 정보는 **각 사이트의 개인정보 처리 방침**의 적용을 받으며, 본 사이트는 이에 대해 책임지지 않습니다.

## 6. 미성년자 보호

본 사이트는 만 14세 미만 사용자를 대상으로 정보를 수집하지 않습니다.

## 7. 권리 행사

본 사이트가 직접 수집하는 개인정보가 없으므로 열람·정정·삭제 요청 대상 정보는 없습니다.
GitHub 인프라 단에서 처리되는 로그에 대한 권리 행사는 GitHub의 정책을 따릅니다.

## 8. 정책 변경

본 방침이 변경될 경우 사이트 상단에 사전 공지하고, 변경일을 본 페이지에 명시합니다. 중대한 변경(예: 광고/분석 도구 도입)은 시행 7일 이전부터 안내합니다.
